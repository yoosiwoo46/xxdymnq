## 📖 游戏简介

《选秀导演模拟器》是一款以选秀节目制作全流程为核心的**模拟经营策略游戏**。玩家扮演选秀节目总导演，在有限的资金和资源下，完成从节目筹备、练习生招募、舞台策划、剪辑营销到总决赛的完整流程。

### 核心体验

- 💰 **资源管理** - 在有限资金下做出最优决策，平衡节目品质与商业收益
- 🎬 **策略抉择** - 每期节目面对随机事件，选择剪辑角度和镜头分配，影响练习生命运
- 📊 **粉圈运营** - 管理不同类型粉丝群体的动态变化，应对舆论危机
- 🤝 **人情博弈** - 处理赞助商要求、练习生关系、导师互动等多方利益
- 📢 **营销博弈** - 通过微博/抖音/豆瓣等平台的营销操作，影响练习生人气和舆论走向

## 🎯 游戏特色

### 12期完整节目流程

| 阶段 | 期数 | 人数变化 | 核心内容 |
|------|------|---------|---------|
| 筹备阶段 | — | 100人 | 节目筹备、导师邀请、练习生确定 |
| 第一阶段 | 第1-3期 | 100人 | 初舞台 + 等级评定 + 主题曲公布 |
| 第二阶段 | 第4-6期 | 100→60人 | 第一次公演（小组对抗）+ 第一次淘汰 |
| 第三阶段 | 第7-9期 | 60→35人 | 第二次公演（位置测评）+ 第二次淘汰 |
| 第四阶段 | 第10期 | 35人 | 第三次公演（外部艺人合作舞台） |
| 第五阶段 | 第11期 | 35→20人 | 第三次淘汰 + 总决赛主题曲公布 |
| 第六阶段 | 第12期 | 20人 | 总决赛主题曲练习室 + 单人曲目排练 |
| 总决赛 | 总决赛 | 20→11人 | 总决赛直播 + 最终出道 |

### 四大核心系统

#### 1️⃣ 剪辑系统
- **4种剪辑方式**：一剪梅 / 突出能力 / 突出问题 / CP线
- **时长管理**：每期正片不超过90分钟，花絮不超过20分钟
- **多维度取材**：演播室、练习室/宿舍、舞台、主线剧情
- **智能筛选**：按公司、能力、等级、粉丝数等多条件筛选练习生

#### 2️⃣ 粉圈系统
- **4类粉丝群体**：唯粉、路人粉、CP粉、黑粉
- **动态变化**：剪辑和营销操作实时影响粉丝构成
- **打投能力**：不同粉丝群体的打投能力各不相同

#### 3️⃣ 营销系统
- **3大平台**：微博、抖音、豆瓣
- **正向/负向营销**：可选择捧红或制造话题
- **CP营销**：双人均可获得CP粉加成
- **逆反心理**：过度营销会触发大众逆反事件

#### 4️⃣ 资源管理系统
- **赞助商系统**：6种类型赞助商，需满足其特殊要求
- **导师系统**：从《甄嬛传》《西游记》等经典作品中随机生成导师
- **音乐版权**：多种歌曲类型，需提前购买版权
- **场地/工作人员**：不同等级影响节目效果

## 🚀 快速开始

### 在线游玩

1. 访问 https://yoosiwoo46.github.io/xxdymnq/
2. 点击"经典模式"开始游戏
3. 完成筹备阶段：选择赞助商、邀请导师、购买版权、租赁场地
4. 进入第1期，开始你的导演之旅！

### 本地运行

```bash
# 克隆仓库
git clone https://github.com/yoosiwoo46/xxdymnq.git

# 进入目录
cd xxdymnq

# 使用任意本地服务器运行
# Python 3
python -m http.server 8080

# Node.js
npx serve

# 然后访问 http://localhost:8080
```
